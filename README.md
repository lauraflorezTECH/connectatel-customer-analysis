# 📊 ConnectaTel — Customer Segmentation & Usage Analysis

## 🎯 Project Overview

Analysis of telecommunications customer behavior during 2024 to identify usage patterns, customer segments, and business opportunities.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Datasets

| Dataset | Description |
|---|---|
| plans.csv | Telecommunications plans |
| users_latam.csv | 4,000 customer records |
| usage.csv | 40,000 usage records |

## 🔍 Analysis Process

1. Data loading and exploration.
2. Data quality assessment.
3. Missing values and invalid data cleaning.
4. Customer-level usage aggregation.
5. Descriptive statistical analysis.
6. Data visualization.
7. Outlier detection using IQR.
8. Customer segmentation.
9. Business recommendations.

## 📈 Key Findings

- Average usage: 5.52 messages, 4.48 calls, and 23.32 call minutes per user with recorded usage metrics.
- Basic and Premium plans showed visually similar usage patterns.
- Extreme values reached 17 messages, 15 calls, and 155.69 call minutes.
- Total call minutes showed a right-skewed distribution.
- High-usage customers represent potential commercial opportunities.

## 👥 Customer Segmentation

### By Age

- Young: Under 30.
- Adult: 30–59.
- Senior: 60 and older.

### By Usage

- Low Usage.
- Medium Usage.
- High Usage.

## 💡 Business Recommendations

- Develop personalized telecommunications plans.
- Offer additional benefits to high-usage customers.
- Encourage medium-usage customers to upgrade.
- Introduce flexible plans for low-usage customers.
- Improve data quality controls.

## 🚀 How to Run

1. Download ConnectaTel_Analysis.ipynb.
2. Open it in Jupyter Notebook or Google Colab.
3. Install the required libraries.
4. Obtain the original project datasets.
5. Adjust the CSV file paths.
6. Run all cells sequentially.

Original datasets are required to reproduce the analysis and are not included in this repository.
